# Нишпорка

Нишпорка — занотуй свою пригоду. Вебзастосунок для планування подорожей.

## Файли

- `index.html` — сторінка, яку бачить користувач.
- `nishporka.css` — спільний стиль з макета V1 (кольори, шрифти, розміри).
- `app.js` — логіка сторінки (поки що лише вигляд «телефон / ноутбук»).

Без фреймворків і без збірки: файли відкриваються в браузері як є.
Сайт публікує GitHub Pages з гілки `main` (корінь репозиторію).
